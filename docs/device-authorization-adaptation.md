# 设备授权接口适配记录

日期：2026-10-25。依据工作区 `unite-tizhi-docs/docs/汇海同步接口文档.md` 最新设备授权及 test_no 契约。目标为 .NET Framework 4.0 / x86，无旧接口兼容、无旧库迁移，未提交或推送。

## 设备身份与使用流程

首次启动调用 `Guid.NewGuid().ToString("D")`，不加前缀，不读取硬件。身份文件保存于 `%LOCALAPPDATA%/Huihai/DataCollection/<安装目录摘要>/device-id.txt`。安装目录摘要仅隔离同一 Windows 用户的不同安装路径；GUID 本身随机生成。业务库中的 `device_no` 只是缓存，身份文件独立于 `HH_Data.db`。相同用户与安装目录下，重启或重建业务库复用设备号。

先持久保存身份，再允许注册。已存在文件损坏、无法读取或与数据库缓存冲突时报告错误，不覆盖旧身份。新用户或新安装路径拥有独立身份；升级应保留用户、安装路径及身份文件。不要在多台电脑间复制身份文件。重新登记的新设备需要管理员重新授权，旧设备由管理员核对后停用。

1. 打开“同步设置”，填写以 `/api/hh` 结尾的接口地址。
2. 点击“保存并检查授权”，客户端仅发送设备号注册。
3. 等待授权或绑定学校时，地址和设备号已保存；可复制只读设备号给管理员。
4. 管理员在平台“体测设备”中绑定学校并启用后，再次检查。
5. 只有注册返回 active 且 info 和本地目标检查均成功，才保存已确认目标并开放同步入口。

## 接口及数据契约

- GET query 携带 `device_no`，名单请求另带 page、per_page。注册 POST 仅有 device_no，成绩 POST 仅有 device_no、items。不再配置或发送旧令牌。
- 成绩行仅含 test_no、code、score、completed_at；每批 1～5000 条，现有业务批次仍为 1000。仅布尔 true ACK 标记已上传，不表示正式录入或评分成功。
- 403、400、422、success=false 或有限限流重试耗尽，停止上传任务；422 展示字段定位，名单脏数据展示 total 和分类数量。网络/临时服务错误有限重试，原始请求体不变。Retry-After 支持秒数及 HTTP 日期。
- 名单仍为可选功能，无本地名单不阻断采集或符合规则的成绩上传。保留整页事务、失败页不写入、此前提交页保留、分页一致性检查与不据缺失记录删除本地学生的行为。
- 名单合并、导入、本地预核对、内存学生索引全部按大小写精确匹配；保留前导零，平台负责身份证大写规范化。校验文本类型、test_no 最长 60、姓名最长 60、班级名最长 100，非法字段不截断。合法年级为 11～16、21～23、31～33、41～44；越界仍按现有规则报告并保护本地年级。
- 六表结构不变；调整 Student.Name、ClassName 及 StudentScore.StudentID 的声明容量，同步修改 DAL 映射。SyncConfig 七项基础配置另有 `local_target_<年度ID>` 目标绑定，所有数据库访问经 DAL。

## 目标变化保护

名单下载和每轮上传前读取 info，比对保存的学校和项目。每个本地年度另绑定接口地址、学校 ID 和平台项目 ID。有该年度名单或任何成绩时禁止更换其平台项目；其他年度有原学校或平台的数据时也禁止直接改绑到新学校/平台。重新保存设置不能跳过保护；需先停止任务、归档并清理旧数据，或在同一学校使用适当的空年度。下载名单期间锁定设置入口，上传/采集窗口原有锁定行为保留。

接口查询不能锁定后续请求目标；info 之后平台变更、学校切换学生标识模式等仍无法完全由客户端识别。平台改绑、切换年度或标识模式时应先暂停同步并核对数据。
